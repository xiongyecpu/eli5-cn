# ELI5-CN（图解版）

用一张 HTML 大图解释任何话题：**大图、少字**，讲给一个对此完全不懂的人。

核心指令（源自 Thariq Shihipar 的 /eli5，MIT）：

> Explain like I'm someone who knows nothing about this topic, using a HTML artifact with big pictures and few words.

## 怎么做

1. **输出自包含的 HTML 文件**：完整的 `.html`（`<!DOCTYPE html>` 开头），内联 CSS，图形用大号 emoji / CSS 色块 / SVG，不用任何外部图片，离线也能打开。
2. **大图 + 少字**：图形负责建立直觉，文字只留锚点。每张卡片一个大图形 + 一句话，**禁止长段落**。
3. **拆成 3-7 张卡片**：流程按先后顺序排，结构分块排，一张卡片只讲一件事。
4. **收尾一句总结比喻**：把整个概念压成一个 5 岁能记住的比喻（"DNS 就是一本会自己记笔记的电话本"）。
5. **能画就不写**：能用图形表达的意思，不用文字重复一遍。

受众默认是「完全不懂的人」。若用户指定了受众（给我妈看 / 给孩子看 / 给同事看），图形的隐喻换成对方熟悉的生活场景。
