# ELI5-CN

> 一个中文本土化的 Agent Skill：把任何复杂话题，用对方熟悉的世界讲清楚。根据受众（孩子、爸妈、爷爷奶奶、领导、同事、客户……）自动调整语气、词汇、类比和深度。

灵感来自 [dreambigou/eli5](https://github.com/dreambigou/eli5)。不是翻译，是重做——类比换成了中国生活场景，并针对中文场景做了两个特化机制：**爸爸视角·十万个为什么** 和 **防诈骗预判**。

## 主打场景：爸爸视角·十万个为什么

5 岁左右的孩子追着问"为什么"，是中文家庭最高频的解释场景——但它和普通解释本质不同：孩子要的不是答案本身，而是"爸爸愿意认真回答我"。

所以本 skill 处理这个场景时，目标排序是：

**保护好奇心 > 一起探索 > 知识准确**

六条原则：

1. **先接住，再回答**——"你观察得真仔细！"被认真对待的感觉比答案重要
2. **答案只给一层**——天为什么是蓝的，答到"蓝色最爱在空气里乱跑"就停；他追问，再给下一层
3. **用他眼前的东西**——杯子、台灯、远处的山；类比不能出 5 岁孩子的生活圈
4. **反问回去**——"你觉得是为什么呢？"教他想，不只是教他听
5. **允许说"不知道"**——"爸爸也不知道，我们一起查查"示范的是探索；严禁好奇心的两大杀手：敷衍（"本来就是这样"）和甩开（"长大你就懂了"）
6. **能动手就别光说**——手电筒照一杯牛奶水，胜过十分钟讲解

```
我女儿5岁，问为什么月亮一直跟着我们走，怎么回答
我儿子问飞机为什么能飞，我自己也说不清升力原理，怎么办
```


## 支持的受众

| 类别 | 例子 |
|------|------|
| **家庭关系** | 孩子、爸妈、爷爷奶奶/外公外婆、配偶、饭桌上的亲戚 |
| **职场角色** | 领导/老板、体制内领导、HR/财务等非技术同事、甲方/客户、技术同事 |
| **年龄** | 5-10 岁、11-17 岁、18-30 岁、30-50 岁、50+ |
| **教育背景** | 小学生、中学生、大学生、研究生/专业人士 |

## 相比原版的差异化设计

- **爸爸视角·十万个为什么**：见上文。专门处理 5 岁好奇宝宝的连环追问。
- **防诈骗预判**：给长辈解释涉及钱、手机、账号、AI 的新事物时，主动接住"这是不是骗人的"的警惕心——先肯定、再区分概念与骗局、最后给一条马上能用的自保建议。绝不说"很安全您别担心"这种空话。
- **一句话汇报版**：职场场景结尾附赠可以直接转发给领导的版本。
- **中文类比素材库**：厨房、菜市场、存折、盖章审批、装修、挂号、家族群……不用 crayons 和 playground。
- **禁用清单**：不居高临下、不堆互联网黑话（抓手闭环赋能）、不硬凹过时热梗、不用失真的类比。

## 安装

```bash
git clone https://github.com/xiongyecpu/eli5-cn.git
cp -r eli5-cn/skills/eli5-cn ~/.claude/skills/eli5-cn
```

然后在 Claude Code 里直接说「我女儿问为什么……」「给我妈讲讲……」「怎么跟领导解释……」即可触发。

## 评测

测试用例在 `eli5-workspace/evals.json`，8 个用例 × 4 条断言 = 32 项检查点，覆盖三大场景：

- **十万个为什么**：月亮提问、「爸爸也不会」的诚实示范
- **家庭长辈**：妈妈×AI大模型、爷爷×手机支付安全
- **职场**：领导×代码重构、HR×数据库、体制内领导×数据上云

**前置条件**：已安装 [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code)，且 skill 已安装到 `~/.claude/skills/eli5-cn/`。

```bash
# 跑全部用例 + 自动评分（skill vs baseline 对比）
python eli5-workspace/run-evals.py

# 只跑一个用例
python eli5-workspace/run-evals.py --test=1

# A/B 对比两个版本的 skill
python eli5-workspace/run-evals.py --a skills/eli5-cn/SKILL.md --b ~/experiments/SKILL-v2.md

# 只评分不重跑
python eli5-workspace/run-evals.py --grade-only
```

脚本做三件事：

1. 每个 prompt 跑两遍——一遍带 skill，一遍裸模型（baseline）
2. 用 Claude 按断言逐条自动评分
3. 输出通过率对比汇总

结果保存在 `eli5-workspace/iteration-N/`，每次运行自动递增。
